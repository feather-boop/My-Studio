My Studio: Android APK project

Upload everything in this folder to the root of a GitHub repository (including the hidden .github folder).
Then open the Actions tab, run "Build Android APK", and download the my-studio-apk artifact when it finishes.
If the hidden .github folder won't upload, use Add file > Create new file and type the name
.github/workflows/build-apk.yml, then paste in the contents of that file.
